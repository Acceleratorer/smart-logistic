# Known issues retained for the thesis report

- The original source notebooks remain in the workspace for comparison; they contain older six-robot and legacy single-robot paths. The merged notebook is the reviewed artifact.
- The smoke gate checks notebook contracts and isolated JavaScript behavior. It does not replace a full Kaggle/Colab run with the real dataset and browser-rendered Three.js scene.
- Collision distance is still sampled by the controller. An independent continuous geometry checker and repeated controlled runs remain open work.
- TN01–TN07 measurements in the thesis are baseline V21 evidence and should not be presented as new five-robot measurements without rerunning them.
